# 风格和间距选项即时响应

日期：2026-10-06。用户要求修改网页风格或间距后立即响应，替代上一轮的选择后手动应用交互。实现、完整本地检查及双框架真实长文验收已通过，真实发布验收进行中。

## 交互规则

Vue、React 中选择主题、枚举参数或布尔参数时立即派发 set-theme，由共享控制器校验和提交。两个内置主题的默认参数完整，首次选择即可建立空内容选择的合法配置；首页和详情随后即时使用相应布局、间距和标签设置，不要求点击“应用风格”。

选择另一主题仍使用其明确声明的默认值，不混入前一主题的专属参数。自动选择项清除时，如果有明确默认值则立即恢复该值；没有默认值则移除字段并由共享校验判断是否有效。false、null 和与对象原型同名的合法字段按原 JSON 契约处理。

扩展主题的文本和数字输入仍可保留未完成草稿，通过“应用风格”提交。主题或选择项的自动提交若缺少必填参数或违反验证器，原有效配置、内容和个人记录保持，表单显示字段错误并保留待完成参数；完成后合法事件自动生效。表单同步不自行派发第二次事件。

普通会话的合法选择沿用自动保存；分享会话的即时修改仅影响当前内存，不改原链接或个人记录，刷新恢复原分享配置，显式保存后才退出分享。详情目标和作者内容保持，样式切换复用已校验内容。
