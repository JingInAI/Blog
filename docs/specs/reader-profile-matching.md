# 自选阅读标签与原文结构化

## 目标与使用方式

用户自行选择阅读目标和兴趣方向描述当前阅读需求，页面据此选择文章及原文片段。不推断用户身份、能力或个人属性。先选风格，再勾选标签；Vue/React 使用相同控件和结果。视觉参数与阅读标签独立，改变风格、间距或恢复默认外观保留阅读标签。

| 分组 | ID | 名称 |
| --- | --- | --- |
| 阅读目标 | concepts | 了解基本概念 |
| 阅读目标 | engineering | 工程实践 |
| 阅读目标 | research | 比较研究路线 |
| 阅读目标 | evaluation | 评估与验证 |
| 兴趣方向 | parameters | 参数与训练 |
| 兴趣方向 | context | 上下文 |
| 兴趣方向 | memory | 记忆 |
| 兴趣方向 | skills | Skill 与技能 |
| 兴趣方向 | harness | 工具与 Harness |
| 兴趣方向 | structures | 演化结构 |
| 兴趣方向 | feedback | 反馈与验收 |
| 兴趣方向 | deployment | 更新与部署 |

标签依据当前 RSI 原文讨论的方向设计。同组采用 OR，不同非空组采用 AND，判定单位是章节自己的文字。例如 engineering + parameters 要求片段同时符合工程实践与参数方向；parameters + memory 可匹配任一方向。未选择标签时沿用原内容选择和全文/摘要展示。

候选范围可选已加载公开目录或手动文章。目录模式可发现未手动勾选的文章，但不改写 contentIds 和顺序。不会自动遍历分页：显示已分析/候选/匹配数量及下一页提示，用户点击“加载更多”扩展结果。“原文全文”显示候选全文，“清除阅读标签”移除 reader 并恢复原手动选择。详情页分析当前文章，允许随时阅读全文。

## 独立派生结构

复用 render-core/processBody 唯一的 remark/Markdown 解析链，按根层级标题划分互不重叠的片段，记录标题层级、父章节、正文块类型、原文位置和 SafeBody 根节点索引。标题之前的内容作为无标题片段；重复标题依靠内容 ID 与序号区分。ContentRecord、原文件及 SafeNode 的作者文字均不改写。

SafeBody.structure 为独立派生结果，schemaVersion/ruleVersion 均为 1。静态及 API 来源使用当前实际读到的完整正文重新生成结构，不读取可能过期的旁路索引。偏移是 body.value 中的 UTF-16 码元位置，endOffset 为排除终点；行号从 1 开始。块、摘录与源位置支持 Unicode 和 Markdown 转义，截取不拆开代理对。

## 匹配规则与依据

透明词表在 packages/render-core/src/reading.ts。搜索标题与本节正文文本、行内代码、列表和表格文字，排除代码块、原始 HTML、图片描述/路径、链接地址、引用和脚注定义。英文词有边界约束，中文按声明词组匹配。作者元数据、网址及文件名不构成兴趣依据。

兴趣方向采用标题优先：标题已明确某些方向时，不因正文对比提及其他方向而添加其他兴趣；标题没有明确方向才回到正文。阅读目标依据本节标题或正文。子章节文字不计入父节自己的命中，匹配父节也不自动展示所有子节。

每项依据包含标签 ID、规则词、标题/正文来源、原文摘录、精确偏移和行号。摘录为源文切片，以文本显示；匹配提示在正文之外，并提供定位按钮。不生成作者未给出的摘要、解释、元数据或结论。

片段视图展示匹配章节及祖先章节自身内容，保留原引言和顺序，排除不匹配的兄弟章节。第一标题前的无标题引言也作为根上下文保留。图片资源 ID、URL、alt/title 和既有重试协议保持。脚注按可见引用保留原定义，并递归保留关联脚注；重复定义仍保留，循环引用终止，不显示未引用的定义。全文模式显示完整原节点。

关键词关联不能证明某篇文章适合特定知识水平、事实正确或可以独立理解。依赖跨章节论证时用户可直接阅读全文。没有命中时如实说明，不生成替代内容；加载/转换失败保留错误与重试，不计为已分析但不匹配。结果只覆盖已加载目录，不能宣称已搜索全部文章。

## 配置与扩展契约

DisplayConfig/version 1 增加可选 reader，旧配置无需迁移，也不隐式加入这个字段。

```json
{ "tagIds": ["engineering", "parameters"], "scope": "catalog", "mode": "matched" }
```

tagIds 必须是已声明且不重复的字符串数组；scope 只允许 catalog/selected，mode 只允许 matched/full。未知字段、非法 JSON、访问器与不支持的值拒绝。读取、作者默认、保存、分享及通知中排队事件共用严格校验。普通会话沿用自动保存；分享会话只修改当前展示，点击“保存为个人配置”才保存并清除分享参数。没有向后台上传标签的新增请求。

控制器接收 set-reader，提供 ViewModel.reader 的统一标签、选择、计数、状态及分页范围。ready 条目提供 reading 的匹配/上下文章节与根节点索引。适配器只展示原节点子集和依据，不另建解析或匹配链；其他框架可实现同一契约。API 按现有接口返回完整 Markdown 即可，不增加必需字段。

前端筛选是展示偏好；公开静态正文仍可直接读取，API 权限继续由服务端负责。

## 文件分析命令

```sh
npm run analyze:content -- content/posts/understanding-rsi.md
```

接受本工程的 JSON frontmatter Markdown，严格解码 UTF-8 并复用原内容校验。源文件只读，结果写入 .generated/reader-analysis/<编码内容ID>.json，含源文件/正文 SHA-256、正文在文件中的偏移、结构、标签和各标签匹配结果。输出与项目输入分离，拒绝指向原文的既有输出符号链接。资源在占位基址下解析，不发送网络请求。

报告通过独立临时文件原子替换输出目录项，已有输出与源文件是硬链接时也不截断原文；写入失败清理临时文件。报告是本地分析产物，位于忽略目录，不进入公开构建；分析草稿不导致发布。浏览器始终从当前正文派生结构，不依赖这个报告。
