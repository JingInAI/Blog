## 原因与行为

Vue 和 React 的首页将已提交的 themeId 和 density 应用到文章容器，但详情页只输出 main 类，导致详情中的主题和间距 CSS 无法匹配。此前 compact 仅改变文章容器的内边距和外边距，正文段落和行距仍相同。表单选项属于未提交草稿，需要点击“应用风格”；此前没有直接说明这一生效步骤。

两个渲染器的详情容器现在应用已提交的主题及间距。简洁列表显示透明背景和底部分隔线，卡片风格显示白色卡片和边框；详情始终显示完整正文，卡片详情使用单列，不将文章或返回按钮拆成首页的两列网格。紧凑模式减小容器留白、卡片网格间隔、元数据间隔、正文行距和段落间距；简洁列表保留无横向卡片内边距的布局。

表单明确提示“调整风格或间距后，点击‘应用风格’更新页面”。选择控件仍编辑草稿，点击按钮后由共享控制器校验和提交；合法配置的个人保存、分享会话和刷新语义保持现有契约。视觉变化不改变正文文字、元数据、图片或当前详情目标。
