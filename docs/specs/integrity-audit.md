## 行为与兼容性

static 内容目录缺失现在报错；可选 site.json 和 posts 缺失仍允许，只要声明的内容根目录确实存在。HTTP 来源继续不读取本地内容；输出保护仅检查路径关系，不解析未使用的文章。

输出目录必须与内容和项目输入分离；dist、忽略目录下的独立产物或独立外部目录仍可使用。已有输出仍采用暂存、备份、提交流程；对同一最终输出的多个构建仍须串行，路径保护不是并发调度器。文件系统检查不承诺抵御外部进程在检查与提交之间主动修改路径。

本地资源引用遵循 URI 路径语义。空格使用 %20，中文按 UTF-8 编码，字面百分号使用 %25，文件名中的 # 使用 %23；不会二次解码。清单与作者正文保持原始引用，发布地址仍由已验证资源映射提供。含歧义的字面百分号路径现在须明确编码。

静态目录描述本次构建的完整已发布集合；API 分页目录仍可以只返回当前页，不要求与静态清单一致。重复脚注的 ID 后缀属于渲染定位数据，不属于新事实，引用仍定位第一条定义。

所有已复现问题均已修复；真实后端与 GitHub Pages 的环境验收继续暂缓，不能以受控本机测试替代线上结果。
